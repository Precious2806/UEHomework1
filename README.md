# UEHomework1

## Домашнее задание 1

Third Person Template, Unreal Engine 5.8.

Добавлены спринт с выносливостью, взаимодействие на E и состояние Sprint в анимациях. Логика на C++, вывод сообщения и анимации настроены в Blueprint.

### Управление

| Действие | Клавиши |
| --- | --- |
| Движение | WASD |
| Камера | Мышь |
| Прыжок | Пробел |
| Спринт | Левый Shift |
| Сообщение Interaction triggered! | E |
| Остановить игру в редакторе | Esc |

### Запуск

Открыть UEHomework1.uproject в Unreal Engine 5.8, собрать C++ модуль и нажать Play на уровне Lvl_ThirdPerson.

## Домашнее задание 2

Сделал уровень `Lvl_Homework2` с двумя охранниками. Препятствия расставляет PCG, для обхода препятствий используется NavMesh.

Охранники ходят вокруг своей начальной позиции. Если замечают игрока, бегут за ним. Если игрок далеко, возвращаются к патрулю. Поведение настроено через `BT_Guard` и `BB_Guard`, персонаж и контроллер написаны на C++.

Дополнительно добавил слух и подозрение. Охранник слышит спринт и идёт проверять место шума. Чем дальше шум, тем шире область поиска. При высоком подозрении область сужается. Если ничего не происходит, охранник возвращается к патрулю.

Для этого сделал свои Service и Task: первый проверяет игрока и обновляет подозрение, второй выбирает точку для патруля или поиска.

### Запуск

Открыть `UEHomework1.uproject` в UE 5.8, собрать C++ и нажать Play на уровне `Lvl_Homework2`.

Управление: WASD, мышь, пробел, Shift для спринта, E для сообщения, Esc для выхода из игры.

Для проверки подойти к охраннику спереди, затем убежать. Чтобы проверить слух, пробежать на Shift за его спиной.
